# FAQ-бот на 5 вопросов (Репетиция хакатона)

Консольный чат-бот для терминала, отвечающий на 5 ключевых вопросов о репетиции хакатона.  
Проект выполнен командой **Jomart Ai**. Стек: **Python 3 (Standard Library)** без внешних зависимостей.

---

## 📌 О проекте

Бот считывает базу знаний из файла `faq.txt` и отвечает на вопросы пользователей по 5 темам:
1. ⏰ **Время** — расписание и длительность репетиции.
2. 👥 **Команда** — состав участников и название команды.
3. 🎯 **Трек** — направление и тема кейса.
4. 📤 **Сдача** — регламент и формат отправки решения (GitHub).
5. 🏆 **Призы** — награды, дипломы и баллы победителям.

Если вопрос не относится ни к одной из тем или не распознан, бот честно сообщает: **«Не знаю»**.

---

## 🚀 Как запустить

Для работы требуется установленный **Python 3.8+**. Установка дополнительных библиотек (`pip`) **не требуется**.

### 1. Интерактивный чат в терминале
```bash
python bot.py
# или
python main.py
```
> Для завершения диалога введите `выход`, `exit` или `quit`.

### 2. Быстрый ответ на один вопрос
```bash
python bot.py "Сколько длится репетиция?"
python bot.py "Что получат победители?"
```

### 3. Запуск встроенных тестов
```bash
python bot.py --test
```

## 🧠 Как устроен поиск совпадений

Вместо тяжеловесных нейросетей и RAG реализован быстрый алгоритм на стандартной библиотеке Python:
- **Нормализация текста**: очистка от пунктуации и приведение к нижнему регистру.
- **Стоп-слова**: фильтрация служебных предлогов и местоимений (чтобы не реагировать на случайные слова «как», «что», «в»).
- **Стемминг и ключевые слова**: сопоставление по корням слов для каждой из 5 категорий.
- **Нечёткое сравнение (difflib SequenceMatcher)**: вычисление похожести формулировок для устойчивости к опечаткам.
- **Порог уверенности**: если совпадений недостаточно, бот выдает fallback-ответ («Не знаю»).
